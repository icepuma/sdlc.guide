# sdlc.guide

[sdlc.guide](https://sdlc.guide) is an opinionated, interactive guide to the software development
lifecycle for agentic engineering teams. It maps the lifecycle as one continuous wheel and explains
the documents that give engineers, managers, and AI agents shared product context. PRD, RFC, and ADR
are available now; the rest is a work in progress.

Questions, ideas, or feedback? [Join the discussion](https://github.com/icepuma/sdlc.guide/discussions).
