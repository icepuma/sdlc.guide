# sdlc.guide

[sdlc.guide](https://sdlc.guide) is an opinionated, interactive guide to the software development
lifecycle for agentic engineering teams. It maps the lifecycle as a continuous flow and explains
the phase work and documents that give teams and AI agents shared product context. All seven phase
pages are available; PRD, RFC, and ADR are the current document guides.

Questions, ideas, or feedback? [Join the discussion](https://github.com/icepuma/sdlc.guide/discussions).
